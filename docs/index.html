Файл таңдалмаған.

Әр фото жіберу алдында браузерде JPEG форматына ауысып, ең ұзын жағы 1600 пиксельге және көлемі 750 КБ дейін кішірейеді. Файлдағы камера мен GPS метадеректері алынып тасталады; формадағы GPS өрісі бөлек сақталады. Құрылғыдағы түпнұсқа файл өзгермейді.
